# Game: Polytope Tropes

Videogame created by Tommy P. Keane using Godot Engine, per the source code in repository: https://github.com/TommyPKeane/learning-gamedev-godot4

## Fixing CORS Issues

GitHub Pages don't support CORS configurations, but others have found that you can workaround this with JavaScript per the code here: https://github.com/kairi003/coi-serviceworker/

This script is then added to the main HTML file of the exported Godot Game when deployed to GitHub Pages.
